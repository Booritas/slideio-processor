# `config` Module Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the `config` module of `slideio-processor`: the immutable `Configuration` and its builder, the shipped standard label vocabulary, the backend capability table, and logging setup. It ships inside `slideio-processor-data`, next to `core`.

**Architecture:**
- `config` is a second OBJECT library, `slideio-processor-config`, linked into the SHARED library `slideio-processor-data` the same way `core` is.
- Layout:
  - public headers under `include/slideio/processor/config/`;
  - sources under `src/config/`, with private helpers in `src/config/detail/`;
  - tests under `tests/config/`, built as their own executable.
- `BackendCapabilities` comes from a header generated at configure time. It is filled in from the OpenCV version Conan resolves. OpenCV is a Conan dependency from this plan on, but nothing links it yet. `pipeline` will be the first module to link it.

**Tech Stack:**
- C++17, CMake ≥ 3.21 and Conan 2.
- GoogleTest `gtest/1.17.0` and RapidJSON `rapidjson/cci.20250205`, as before.
- New: `opencv/4.14.0`, the version SlideIO pins. It is used here only for its version number.

**Spec:** `docs/superpowers/specs/sds/02-config.md` (SDS 02), under `docs/superpowers/specs/sds/00-conventions.md` (SDS 00). `core`'s contract is `docs/superpowers/specs/sds/01-core.md` and the headers in `include/slideio/processor/core/`. Requirement IDs refer to `docs/requirements.md`.

## Global Constraints

Every constraint of the `core` plan (`docs/superpowers/plans/2026-10-17-core.md`, "Global Constraints") holds unchanged. In summary:
- C++17, in `namespace slideio::processor`, with private helpers in `slideio::processor::detail`.
- The export macro is `SLIDEIO_PROCESSOR_DATA_EXPORTS`. Include it from `<slideio/processor/core/export.hpp>`.
- **ABI rules (C-2):**
  - Pimpl through `std::unique_ptr<Impl>`.
  - Every definition out of line, with no logic in headers.
  - No STL container, `std::string` or template in a public signature, except `std::shared_ptr`.
  - Every `enum class` is `: int32_t`.
- **Strings (C-4):** in, `const char*` UTF-8; paths opened through `std::filesystem::u8path`.
- **Errors (C-6, as amended):** `std::bad_alloc` is the only non-`ProcessorError` that may cross the boundary. Translate other exceptions to `IoError` (I/O) or `InternalError`, with `what()` as the cause.
- **Moved-from rule (C-8):** the source reads as default.
- **Documentation:** every public entity gets a Doxygen comment covering parameters, return, `@throws`, thread-safety and requirements. Every test file starts with `// Requirements: …`.

Added or sharpened here:
- **Signatures are SDS-exact.** Copy every signature in SDS 02 character for character. The only additions are the members ruled below (G1, G3).
- **OpenCV is never linked by `slideio-processor-data`.** `config` may call `find_package(OpenCV)` only to read its version. A configure-time guard (Task 1) fails the build if OpenCV reaches either library's link list.

## Rulings on spec gaps

SDS 02 leaves the following open. Each ruling binds this plan and is to be folded back into SDS 02 afterwards.

| # | Gap | Ruling |
|---|---|---|
| G1 | `Configuration` has no move assignment. `ConfigurationBuilder` has no copy or move members. | `Configuration` gets `Configuration& operator=(Configuration&&) noexcept`. `ConfigurationBuilder` gets the full copy and move set. Moved-from objects read as `defaults()`, per C-8. |
| G2 | `defaults()` and `processDefault()` are `noexcept` but must allocate (the pimpl and its strings). | Allocation failure there calls `std::terminate`. Document it as fatal, the way C-6 treats the log setters' lock. |
| G3 | `processDefault()` returns a reference that `setProcessDefault()` would invalidate. | Every published process default is immutable and is never destroyed before process exit. `setProcessDefault` publishes a new instance under a mutex and keeps every earlier one alive. A reference from `processDefault()` therefore stays valid and keeps reading the values it was published with. The cost is one `Configuration` per call, and the SDS says the call is made at startup only. |
| G4 | The default worker count. | `std::thread::hardware_concurrency()`, or 1 when that returns 0. It is read when `defaults()` or `Configuration()` runs. |
| G5 | What `build()` rejects. | `memoryCeilingBytes <= 0`, `workerCount < 1`, `tileWidth < 1`, `tileHeight < 1`, `eventPollIntervalMs < 1`, `objectBatchSize < 1`, a `logLevel` outside `Trace..Off`, and a null `logFilePath` or `scratchDirectory`. There are no upper bounds (the project's "no fixed limits" rule). Setters never validate (C-10). A null string is recorded and reported by `build()`. |
| G6 | `build()`'s message. | `"ConfigurationBuilder: invalid configuration: "`, then one clause per offending setting in declaration order, joined by `"; "`. Each clause has the form `<setting> must be <rule> (got <value>)`, or `<setting> must not be null` for the strings. `<setting>` is the getter's name: `memoryCeilingBytes`, `workerCount`, `tileWidth`, `tileHeight`, `eventPollIntervalMs`, `objectBatchSize`, `logLevel`, `logFilePath`, `scratchDirectory`. |
| G7 | Standard label ids. These are a persistence contract. | Label ids are `1..10`, in the order of the SDS 02 table: `tumour`=1, `stroma`=2, `necrosis`=3, `immune`=4, `lymphocyte`=5, `positive`=6, `negative`=7, `artefact`=8, `ignore`=9, `other`=10. `labelAt(i)` is `LabelId(i + 1)`. `version()` and `standardVocabularyVersion()` return 1. |
| G8 | Name lookup. | `findLabel` is an exact, case-sensitive byte match, so `"Tumour"` is not found. A null or empty name returns false. Mapping QuPath's spellings is `storage`'s import policy (UR-RES-19), not this table's. |
| G9 | Non-standard ids passed to `labelName`, `conventionalLayer` and `ontologyRef`. | All three return `""` and never throw; keep the SDS signatures as they are. `labelAt` throws `InvalidArgumentError` for an index outside `[0, labelCount())`. `conventionalLayer` returns the table's text exactly: `"region or cell"`, `"region"`, `"cell"` or `"any"`. |
| G10 | How the backend type sets are derived. | A private pure function, `detail::backendTypesForOpenCvMajor(int32_t major)`, returns the computable set. For major ≥ 5 that is all 11 types. Otherwise it is all except `UInt32`, `Int64` and `UInt64`. `storageOnlyTypes()` is `DataTypeSet::all()` minus the supported set. `supports(DataType::Unknown)` is false. CMake requires OpenCV ≥ 4. |
| G11 | The log file's format and mode. | The file is opened in append mode and flushed after every line. A line is `<UTC time as YYYY-MM-DDTHH:MM:SS.mmmZ> <LEVEL> <message>\n`, with `LEVEL` one of `TRACE`, `DEBUG`, `INFO`, `WARNING`, `ERROR`. The stderr sink writes the same line. If the file cannot be opened, the call throws `IoError` naming the path, and the sink and level already installed stay as they were. |
| G12 | `configureLogging(LogSinkPtr, LogLevel)` ownership, and a null sink. | `LogSinkPtr` is a `shared_ptr`, so the library shares ownership. Document that instead of SDS's "the caller owns it". A null sink installs core's discarding null sink. A level outside `Trace..Off` throws `InvalidArgumentError` and changes nothing. |
| G13 | The test helper `temp_path.hpp` lives in `tests/core/`. | Move it to `tests/common/temp_path.hpp` and use it from both test executables (Task 1). |

## Review Focus

1. **A thread reading `processDefault()` while startup code calls `setProcessDefault()`.** The reference it holds must stay valid and keep its old values (G3). This is pinned in Task 2.
2. **A builder with several bad settings.** `build()` must name every offender, not just the first (G5, G6). This is pinned in Task 2.
3. **A non-ASCII log file path on Windows,** such as `ü_日本.log`. It must open and receive lines. This is pinned in Task 4.
4. **A log file in a directory that does not exist.** This must throw `IoError` naming the path, and the previous sink and level must stay installed. This is pinned in Task 4.
5. **A label name that differs only in case, or a null name.** `findLabel` must return false and not crash (G8). This is pinned in Task 3.
